Your screen-aware study tutor.

DigiTutor is packaged for Windows x64 and universal macOS. Use a hotkey to capture screen context, ask by voice or text, and stream an explanation with rendered math, optional read-aloud, and suggested resources.

⬇ Download for Windows ⬇ Download for Mac (Apple Silicon + Intel)

Latest release · Windows x64 · Apple Silicon + Intel Mac

On first launch Windows SmartScreen may warn (the app isn't code-signed yet). Click More info → Run anyway. On Mac, allow the app in System Settings → Privacy & Security if Gatekeeper blocks it. These packages are tested as builds, but not yet across every hardware and provider combination.

① Trigger

Press your global hotkey (default Ctrl/Cmd+Shift+Space) and DigiTutor screenshots the screen your cursor is on. Or use the mic-only hotkey to just ask by voice.

② Ask

Speak or type your question in the popup. After a one-time model download, Whisper transcribes microphone audio locally - no cloud speech API.

③ Learn

Answers stream back with Markdown and rendered LaTeX, can be read aloud in a natural voice, and can include resource links suggested by the selected AI model.

You bring your own AI key

DigiTutor runs on your Claude (Anthropic) or OpenAI API key. Electron protects a saved key with OS-backed secure storage; if that protection is unavailable, DigiTutor refuses to save the key. Provider requests go directly from the desktop app - there are no DigiTutor accounts, subscriptions, or intermediary servers.

Get a key: Anthropic Console · OpenAI API keys

Installing

Windows

  1. Download and run DigiTutor-Setup.exe.
  2. If SmartScreen appears, choose More info → Run anyway.
  3. Pick an install location and finish - DigiTutor lands in your system tray.
  4. Open Settings, paste your API key, and press your hotkey to start.

macOS

  1. Download and open DigiTutor.dmg, then drag DigiTutor to Applications.
  2. If Gatekeeper blocks it, allow DigiTutor in System Settings → Privacy & Security.
  3. Allow Screen Recording and Microphone access when macOS asks.
  4. Open Settings, paste your API key, and press Cmd+Shift+Space to start.
