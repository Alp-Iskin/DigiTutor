Your screen-aware study tutor.

Hit a hotkey anywhere in Windows. DigiTutor grabs what's on your screen, listens to your question, and answers with depth - math rendered, read aloud in a natural voice, with real sources.

⬇ Download for Windows

Latest release · Windows 10 / 11 · ~88 MB

On first launch Windows SmartScreen may warn (the app isn't code-signed yet). Click More info → Run anyway.

① Trigger

Press your global hotkey (default Ctrl+Shift+Space) and DigiTutor screenshots the screen your cursor is on. Or use the mic-only hotkey to just ask by voice.

② Ask

Speak or type your question in the popup. Speech is transcribed locally with an offline Whisper model - no cloud mic streaming.

③ Learn

Answers stream back with Markdown and rendered LaTeX, can be read aloud in a natural voice, and end with curated, reputable sources.

You bring your own AI key

DigiTutor runs on your Claude (Anthropic) or OpenAI API key, which you paste once in Settings. It's stored encrypted on your device only - it never touches our servers, and there are no accounts or subscriptions here.

Get a key: Anthropic Console · OpenAI API keys

Installing

  1. Download and run DigiTutor-Setup.exe.
  2. If SmartScreen appears, choose More info → Run anyway.
  3. Pick an install location and finish - DigiTutor lands in your system tray.
  4. Open Settings, paste your API key, and press your hotkey to start.
