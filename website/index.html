Ask questions without leaving what you're studying.

DigiTutor stays in your system tray while you work through notes, slides, or problem sets. Open it with a hotkey, ask by text or voice, and include a screenshot when your question needs visual context.

Latest release · Windows x64 · Apple Silicon + Intel Mac

Both installers are unsigned. I smoke-tested the Mac build; the Windows installer is built and checked in GitHub Actions but still needs a real-device test. Windows may show SmartScreen, and macOS may ask you to approve the app in Privacy & Security.

① Bring your work with you

Press Ctrl/Cmd+Shift+Space to open DigiTutor with a screenshot of what you are studying, or use the mic-only hotkey when you do not need screen context.

② Ask

Speak or type your question in the popup. After a one-time model download, Whisper transcribes microphone audio locally - no cloud speech API.

③ Learn

Get a streamed explanation with Markdown and rendered LaTeX. You can have it read aloud or ask the selected AI model to suggest useful resource links.

You bring your own AI key

DigiTutor uses your Claude (Anthropic) or OpenAI API key. It saves the key through Electron's OS-backed secure storage; if that protection is unavailable, the app will not save a new key. Requests go directly from the desktop app to your selected provider. There are no DigiTutor accounts, subscriptions, or intermediary servers.

Get a key: Anthropic Console · OpenAI API keys

Installing

Windows

  1. Download and run DigiTutor-Setup.exe.
  2. If SmartScreen appears, choose More info → Run anyway.
  3. Pick an install location and finish - DigiTutor lands in your system tray.
  4. Open Settings, paste your API key, and press your hotkey to start.

macOS

  1. Download and open DigiTutor.dmg, then drag DigiTutor to Applications.
  2. If Gatekeeper blocks it, allow DigiTutor in System Settings → Privacy & Security.
  3. Allow Screen Recording and Microphone access when macOS asks.
  4. Open Settings, paste your API key, and press Cmd+Shift+Space to start.
